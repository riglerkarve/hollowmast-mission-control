Panel race

Mounts every panel and tears it down immediately, while its first fetch is still in flight, then waits for that fetch to land. Counts what throws.

Why this page exists rather than clicking around. The failure it hunts — unmount() sets root = null, the fetch resolves, the continuation dereferences null — only reproduces with a COLD module. Once a panel module is cached the dynamic import resolves in a microtask, the teardown window closes, and the bug is invisible. So every run here imports with a fresh ?v=, which is a different URL and therefore a different module. Clicking around a warm dashboard measures nothing and reads as good news.
